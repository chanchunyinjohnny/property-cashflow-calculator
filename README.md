# 收租樓現金流計算器

以繁體中文比較香港住宅放租的現金流、按揭及全現金 IRR。純 HTML、CSS、JavaScript，在瀏覽器計算，沒有伺服器、API、外部字型或分析追蹤依賴。

網站：[開啟計算器](https://chanchunyinjohnny.github.io/property-cashflow-calculator/)

## 使用

1. 在首頁填樓價、預計月租、初始裝修預算及每月管理費。管理費預設 HK$1,000／月，可按代理或管理處提供的數字修改。
2. 在方案 B 只填不同的數值；留白沿用 A，填 `0` 就是零。
3. 同時比較持貨 3、5、10 年的結果，查看年度現金流、退出淨回款、稅前／稅後 IRR（預設只扣普通物業稅，可選個人入息課稅扣按揭利息），以及目標回報所需售價。
4. 用「儲存到這部裝置」保存看樓情境，亦可下載 CSV 或情境 JSON。JSON 可匯入還原；本機保存只適用於同一瀏覽器，清除網站資料後便會消失。

輸入值及匯入檔案只在本機瀏覽器處理，沒有上傳程式。網站及程式碼公開；預設值是計算假設，沒有特定物業地址、租客資料或銀行文件。

手機看樓時，直接在首頁改四個主要數值即可更新結果。每月管理費乘 12 後計入年度成本，包括空置月份；詳細假設及 JSON 的管理費仍採年額，與首頁月額同步。毋須登入或安裝程式；按揭、費用、稅務及逐年覆寫仍可在同一頁面調整。頁面亦可下載聯動 Excel 計算器，該 Excel 是預設假設版本；CSV 及情境 JSON 才是目前網頁輸入的匯出。Excel 未有 2026-09-20 新增的銀行估價、罰息期及個人入息課稅選項；在預設假設下兩者結果相同。

## 模型口徑

預設費用沿用專案的收租算例及業主成本筆記，屬預算假設，並非特定樓盤報價：

| 項目 | 預設 | 計入方式 |
|---|---:|---|
| 管理費 | 每月 HK$1,000 | 首頁基本輸入；月額 × 12，全年照付，包括空置期 |
| 保險 | 每年 HK$2,500 | 需按實際出租用途核保 |
| 日常維修 | 每年 HK$8,000 | 年度成本 |
| 年度大修支出 | 新方案預設 HK$0（尚未估算） | 可填每年預計實付款；已知工程按付款年份另列，0 不代表沒有大修風險 |
| 招租佣金 | 每次半個月租金 | 按推算／覆寫的招租年度扣除 |
| 買入／出售佣金 | 各 1% | 分別按買價／售價計 |
| 買入／出售律師及雜費 | 各 HK$15,000 | 在買入／退出時計入 |
| 差餉、地租、印花、物業稅 | 按模型規則推算 | RV 或稅務參數可覆寫；不當作全數物業都適用同一契約 |
| 按揭成數 | 70% | 金管局上限 70%；按樓價與銀行估價較低者計，估價填 0 即當估足價 |
| 按揭年期 | 20 年 | 最長 30 年（金管局新造按揭上限） |
| 清還費／回贈追討 | HK$0；罰息期 3 年 | 只在罰息期內出售才扣，3／5／10 年分別判斷 |
| 個人入息課稅 | 0＝不選 | 填邊際稅率後，按揭口徑扣出租月份利息（上限為該物業 NAV），與普通物業稅取較低者 |

已知大維修或特別集資請按付款年份填「各年大修／額外工程」，只填尚未計入管理費、初始裝修或年度維修的同一筆支出。自己的未花備用金仍是現金，不填作費用；實際繳交法團基金則計入一次，不能再重扣由基金支付的工程。租客按金不是收入。樓況、承保、管理費及重大工程仍需以實際文件取代預算。

- 由聯動 Excel 的方案 A／B 及原始算例移植，新增持貨 3、5、10 年比較。使用固定月租、固定按息及按月攤還。
- 自動模式由月租估算全年差餉租值，並由租期推算各年新簽／續租次數。這些是可覆寫的簡化假設；估算差餉租值並非差估署的實際評估。
- IRR 使用年末現金流近似，並非依實際付款日期計算的 XIRR。只在現金流恰好轉號一次時顯示 IRR；其他情況以 NPV 輔助判斷。
- 買入現金流包括首期／全款、買入印花稅、佣金、雜費及初始裝修。售出時扣售樓費用、剩餘貸款及清還費；不重複把已還本金當作收入。
- 首年裝修／招租空窗與第二年起的年度空置分開。租約內免租期只調整租約印花稅稅基，實收租金由空窗輸入控制。
- 每年日常維修 HK$8,000 是可改預算，沒有全港平均依據。新方案不再假定每年必花 HK$10,000 大修；首頁標示尚未估算，可在即時輸入填年度支出或按年填已知工程。敏感度的 0／5,000／10,000／20,000 全是示例。已保存方案和原例仍保留其舊金額。
- 普通個人物業稅按可課稅租金、可扣差餉、標準修葺扣減及稅率計算。可選填個人入息課稅邊際稅率：按揭口徑稅款＝max(0, NAV − 出租月份利息) × 邊際稅率，並與物業稅取較低者（稅務局會自動比較）。這是單一邊際稅率近似，並非完整個人稅單，亦不是公司稅務模型。
- 另顯示非自用住宅 DSR 50% 所需最低月入（每月供款 ÷ 50%），未計其他債務、擔保及銀行如何計租金收入，只作初步參考。
- 出售利潤當作資本增值，沒有計利得稅。如稅務局按客觀證據認定買入時意圖轉售圖利，利潤須課利得稅（個人首 HK$2,000,000 按 7.5%，其餘 15%），稅後 IRR 會高估；見[稅務局物業交易 FAQ](https://www.ird.gov.hk/eng/faq/pty_tran.htm)。其他未計或已簡化的項目列在網頁「來源與口徑」分頁的「使用時要注意」。
- 比較用債券回報是可調門檻假設，並非可成交報價；不代表已完成匯率、投資者稅務或風險對齊。

### 規則來源

模型基準為 2026-09-16；租約印花稅來源於 2026-09-19 核對，網頁移植於 2026-09-20，並於同日重讀下列官方來源核對算法。2026-09-20 另作香港規則覆核，加入按揭年期上限、罰息期、銀行估價、DSR 月入參考及個人入息課稅選項，該次規則修改未改預設結果。同日大修覆核其後將新方案年度大修由 HK$10,000 改為 HK$0（未估算），網頁與下載 Excel 已同步。規則來源及適用日期應在實際交易前再核實。

- [稅務局：從價印花稅](https://www.ird.gov.hk/eng/faq/avd.htm)，模型採 2026-02-26 起住宅 Scale 2 稅階。
- [稅務局：租約印花稅指引](https://www.ird.gov.hk/eng/pdf/irsd119.pdf)，固定月租及整月租期，含免租、向上進位、副本及業主分攤。
- [政府：印花稅率](https://www.gov.hk/en/residents/taxes/docs/IRSD123(E).pdf)。
- [差估署：住宅累進差餉](https://www.rvd.gov.hk/tc/faqs/progressive_rating_system.html)，模型不計季度寬減。
- [稅務局：物業稅](https://www.ird.gov.hk/eng/faq/pty.htm)。
- [稅務局：個人入息課稅](https://www.ird.gov.hk/eng/faq/pa.htm)及[利息扣除說明](https://www.ird.gov.hk/eng/pdf/bir60_int_e.pdf)：只可扣出租期間利息，上限為該物業應評稅淨值；選擇不利時稅務局按分開評稅。
- [金管局：按揭成數及供款比率](https://www.info.gov.hk/gia/general/202410/16/P2024101600258p.htm)，2024-10-16 起所有住宅按揭成數上限 70%、非自用 DSR 50%。
- [金管局：按揭年期上限](https://www.info.gov.hk/gia/general/201209/14/P201209140578.htm)，2012-09-14 起新造物業按揭最長 30 年。

副本原稅不足 HK$5 的例外沿用舊 Excel，以 [2016 年立法會文件附表第 101 頁](https://www.legco.gov.hk/yr15-16/chinese/bills/brief/b201601151_brf.pdf) 支持；最新官方摘要只簡寫每份 HK$5，未完成 2026 合併法例全文逐頁核對。

### 大修假設依據

- [市建局，2024-03-29](https://www.ura.org.hk/tc/news-centre/press-releases/20240329)：按個別樓宇十年工程預算及供款計劃安排，沒有每戶固定每年一萬元的通用數字。
- [民政事務總署《建築物管理條例指南》第九章](https://www.buildingmgt.gov.hk/file_manager/tc/documents/bmo_guide/ch9_tc.pdf)：公用部分維修及基金支出須按法團預算、公契及分攤安排核對。
- 初始裝修主要是單位內工程，不能據此推定大廈外牆、升降機等無須維修。未估大修的回報只供初篩，不能當成完整成本回報。

### 計算核對

採獨立按月攤還計算覆核網頁模型。以樓價 400 萬、月租 17,000、裝修 30 萬、自動 RV 204,000、兩年租約、七成按揭 3%／20 年、樓價不變及尚未列入大修為例，3／5／10 年按揭普通物業稅後 IRR 分別約為 **−6.8517%／−2.6167%／0.5885%**。四種回報口徑共 12 個 IRR、12 個 NPV 及剩餘貸款與獨立計算一致。這是模型一致性證據，不代表租金、出售價或未來成本可以實現。

## 本機執行及驗證

在此資料夾開啟靜態 HTTP 服務，再用瀏覽器開啟網址。以 Python 內建服務為例，Python 只用於本機預覽，不是網站運算依賴：

```sh
python3 -m http.server 8857 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8857/`。瀏覽器 ES modules 需要 HTTP，請勿直接雙擊 HTML 用 `file://` 開啟。

Node.js 22 以上可跑計算測試，不需安裝 npm 套件：

```sh
npm test
```
