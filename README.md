# 收租樓現金流計算器

以繁體中文比較香港住宅放租的現金流、按揭及全現金 IRR。純 HTML、CSS、JavaScript，在瀏覽器計算，沒有伺服器、API、外部字型或分析追蹤依賴。

網站：[開啟計算器](https://chanchunyinjohnny.github.io/property-cashflow-calculator/)

## 使用

1. 在首頁填樓價、預計月租及初始裝修預算。其他設定先用已標示的預設假設。
2. 在方案 B 只填不同的數值；留白沿用 A，填 `0` 就是零。
3. 同時比較持貨 3、5、10 年的結果，查看年度現金流、退出淨回款、稅前／普通物業稅後 IRR，以及目標回報所需售價。
4. 用「儲存到這部裝置」保存看樓情境，亦可下載 CSV 或情境 JSON。JSON 可匯入還原；本機保存只適用於同一瀏覽器，清除網站資料後便會消失。

輸入值及匯入檔案只在本機瀏覽器處理，沒有上傳程式。網站及程式碼公開；預設值是計算假設，沒有特定物業地址、租客資料或銀行文件。

手機看樓時，直接在首頁改三個主要數值即可更新結果。毋須登入或安裝程式；按揭、費用、稅務及逐年覆寫仍可在同一頁面調整。頁面亦可下載聯動 Excel 計算器，該 Excel 是預設假設版本；CSV 及情境 JSON 才是目前網頁輸入的匯出。

## 模型口徑

預設費用沿用專案的收租算例及業主成本筆記，屬預算假設，並非特定樓盤報價：

| 項目 | 預設 | 計入方式 |
|---|---:|---|
| 管理費 | 每月 HK$1,000 | 全年照付，包括空置期 |
| 保險 | 每年 HK$2,500 | 需按實際出租用途核保 |
| 日常維修 | 每年 HK$8,000 | 年度成本 |
| 預計更新／大修支出 | 每年 HK$10,000 | 當作當年花掉，並非可退回的閒置備用金 |
| 招租佣金 | 每次半個月租金 | 按推算／覆寫的招租年度扣除 |
| 買入／出售佣金 | 各 1% | 分別按買價／售價計 |
| 買入／出售律師及雜費 | 各 HK$15,000 | 在買入／退出時計入 |
| 差餉、地租、印花、物業稅 | 按模型規則推算 | RV 或稅務參數可覆寫；不當作全數物業都適用同一契約 |

已知大維修或特別集資可按實際年份補入「額外工程」，只填超出已列支出的部分。租客按金不是收入。樓況、承保、管理費及重大工程仍需以實際文件取代預算。

- 由聯動 Excel 的方案 A／B 及原始算例移植，新增持貨 3、5、10 年比較。使用固定月租、固定按息及按月攤還。
- 自動模式由月租估算全年差餉租值，並由租期推算各年新簽／續租次數。這些是可覆寫的簡化假設；估算差餉租值並非差估署的實際評估。
- IRR 使用年末現金流近似，並非依實際付款日期計算的 XIRR。只在現金流恰好轉號一次時顯示 IRR；其他情況以 NPV 輔助判斷。
- 買入現金流包括首期／全款、買入印花稅、佣金、雜費及初始裝修。售出時扣售樓費用、剩餘貸款及清還費；不重複把已還本金當作收入。
- 首年裝修／招租空窗與第二年起的年度空置分開。租約內免租期只調整租約印花稅稅基，實收租金由空窗輸入控制。
- 每年維修及大修預留當作當年支出；未花預留不自動於出售時退回。額外工程只填超出這些預留的成本。
- 普通個人物業稅按可課稅租金、可扣差餉、標準修葺扣減及稅率計算。不是個人入息課稅或公司稅務模型。
- 比較用債券回報是可調門檻假設，並非可成交報價；不代表已完成匯率、投資者稅務或風險對齊。

### 規則來源

模型基準為 2026-09-16；租約印花稅來源於 2026-09-19 核對，網頁移植於 2026-09-20，並於同日重讀下列官方來源核對算法。規則來源及適用日期應在實際交易前再核實。

- [稅務局：從價印花稅](https://www.ird.gov.hk/eng/faq/avd.htm)，模型採 2026-02-26 起住宅 Scale 2 稅階。
- [稅務局：租約印花稅指引](https://www.ird.gov.hk/eng/pdf/irsd119.pdf)，固定月租及整月租期，含免租、向上進位、副本及業主分攤。
- [政府：印花稅率](https://www.gov.hk/en/residents/taxes/docs/IRSD123(E).pdf)。
- [差估署：住宅累進差餉](https://www.rvd.gov.hk/tc/faqs/progressive_rating_system.html)，模型不計季度寬減。
- [稅務局：物業稅](https://www.ird.gov.hk/eng/faq/pty.htm)。

副本原稅不足 HK$5 的例外沿用舊 Excel，以 [2016 年立法會文件附表第 101 頁](https://www.legco.gov.hk/yr15-16/chinese/bills/brief/b201601151_brf.pdf) 支持；最新官方摘要只簡寫每份 HK$5，未完成 2026 合併法例全文逐頁核對。

### 計算核對

採獨立按月攤還計算覆核網頁模型。以樓價 400 萬、月租 17,000、裝修 30 萬、自動 RV 204,000、兩年租約、七成按揭 3%／20 年及樓價不變為例，3／5／10 年按揭普通物業稅後 IRR 分別約為 **−7.5042%／−3.2314%／0.0673%**。四種回報口徑共 12 個 IRR、12 個 NPV 及剩餘貸款與獨立計算一致。這是模型一致性證據，不代表租金、出售價或未來成本可以實現。

## 本機執行及驗證

在此資料夾開啟靜態 HTTP 服務，再用瀏覽器開啟網址。以 Python 內建服務為例，Python 只用於本機預覽，不是網站運算依賴：

```sh
python3 -m http.server 8857 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8857/`。瀏覽器 ES modules 需要 HTTP，請勿直接雙擊 HTML 用 `file://` 開啟。

Node.js 22 以上可跑計算測試，不需安裝 npm 套件：

```sh
npm test
```
